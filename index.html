XX年度盛會售票系統

打造一個可以讓團隊夥伴體驗搶票刺激感的網站。

  • Claude Code
  • Vibe Coding
  • Google Sheets

這套系統是我不斷跟 Claude Code 對話迭代出來的成果,過程中裝好各種開發環境並串接到 GitHub 進行版本控管,Google Sheets 則用來匯出報名與購票數據。從零到上線大約花了一週,最大的挑戰是環境安裝與層出不窮的 bug;介面風格則是不斷參考其他網站,再依照使用者實際回饋持續調整而成。上線後,團隊第一次擺脫過去用 Google 表單登記票券的方式,體驗到真正的搶票節奏與刺激感——這也是我第一次完整走過 vibe coding 流程的作品,奠定了後續運用 AI 協作開發的基礎。
