# Austinverse

個人作品集網站。純 vanilla HTML / CSS / JS,無框架、無建置工具,部署於 GitHub Pages。

## 檔案結構

- `index.html` — 頁面結構(Header / Hero / Work / About / Footer)
- `style.css` — 樣式(深色主題、單一強調色、響應式,斷點 768px)
- `script.js` — 語言切換(zh/en)、行動版導覽選單、作品卡片展開/收合、捲動淡入動畫

## 開發

不需要建置流程,直接以任意靜態伺服器開啟 `index.html` 即可,例如:

```bash
python3 -m http.server 8080
```

## 內容狀態

目前頁面文案皆為佔位符(`[PLACEHOLDER]`),尚待補上實際內容。
